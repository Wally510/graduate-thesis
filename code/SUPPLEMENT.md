## 下载与恢复

[thesis-supplement-v1](https://github.com/Wally510/graduate-thesis/releases/tag/thesis-supplement-v1) 是补充归档下载入口。上传期间该 Release 保持草稿，链接在全部附件校验并发布后才对外可用；以仓库首页的上传状态为准。

下载该 Release 内全部 `thesis-supplement-*.zip`，按 `SHA256SUMS.txt` 核验，再解压到同一父目录，得到 `thesis_supplement/`。每个 ZIP 独立可解压，不要拼接；原目录结构保留。补充归档中的普通文件直接解压即可，不需要主归档的去重恢复脚本。

附件 `archive-manifest.json` 记录逐文件 SHA-256，`excluded-paths.json` 记录排除范围。补充归档包含自身保存的模型权重；它不替换原 `model-weights-v1`。
